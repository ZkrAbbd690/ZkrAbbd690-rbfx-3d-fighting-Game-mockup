## Core Design: Asymmetric Ranges

| | **Rifleman** | **Axe Warrior** |
|--|-------------|-----------------|
| **Range** | Long (keep distance) | Short (close gap) |
| **Goal** | Kite, shoot, reload | Rush, flank, punish reload |
| **Weakness** | Slow turn, reload windows | Exposed during approach |
| **AI Feel** | *Calculated, nervous* | *Aggressive, relentless* |

---

## Recommended AI Architecture: **Utility AI + State Machine Hybrid**

Why? State machines are too rigid for the rifleman's complex positioning decisions. Pure behavior trees overcomplicate the warrior's simple "get close and hit" loop.

```
┌─────────────────────────────────────────┐
│  RIFLEMAN (Utility AI)                  │
│  Scores actions every 0.2s:             │
│  ├─ "Shoot"      : high if target in    │
│  │   sight, ammo > 0, clear LOS         │
│  ├─ "Retreat"    : high if target       │
│  │   too close, or reloading            │
│  ├─ "Reload"     : high if ammo 0,      │
│  │   safe distance                       │
│  ├─ "Reposition" : high if LOS blocked, │
│  │   or flank angle bad                 │
│  └─ "Melee bash": desperation if        │
│     cornered (rifle stock strike)       │
│                                         │
│  Picks highest score, adds noise for    │
│  "human" imperfection                   │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│  AXE WARRIOR (Hierarchical State Machine)│
│                                         │
│  ┌─ CHASE ─────────────────────────┐    │
│  │  ├─ Sprint directly at target   │    │
│  │  │  (high visibility, scary)    │    │
│  │  └─ If shot while sprinting →   │    │
│  │     DODGE_WEAVE (zigzag)       │    │
│  │     then resume CHASE          │    │
│  └─────────────────────────────────┘    │
│              ↓ close enough             │
│  ┌─ ATTACK ────────────────────────┐     │
│  │  ├─ Windup (telegraph, 0.4s)  │     │
│  │  │  → player can interrupt?   │     │
│  │  ├─ Swing (active hitbox)      │     │
│  │  └─ Recovery (vulnerable)      │     │
│  │     → rifleman can punish      │     │
│  └─────────────────────────────────┘    │
│              ↓ missed / blocked         │
│  ┌─ RECOVER ──────────────────────┐     │
│  │  Brief stumble, then CHASE     │     │
│  └─────────────────────────────────┘    │
│                                         │
│  SPECIAL: If rifleman reloading →     │
│  SPRINT_ATTACK (no windup, surprise)    │
└─────────────────────────────────────────┘
```

## Key Tactical Behaviors to Implement

### Rifleman — **The Kiting Problem**

```cpp
float Utility_Retreat(const Vector3& myPos, const Vector3& enemyPos, 
                      float enemySpeed, float myAmmo, float reloadProgress) {
    float dist = (enemyPos - myPos).Length();
    float danger = 1.0f - Clamp(dist / 15.0f, 0.0f, 1.0f); // 15m = safe zone
    
    // Urgency spikes if reloading or cornered
    if (reloadProgress > 0.0f) danger *= 2.0f;
    if (dist < 5.0f) danger *= 3.0f; // melee range panic
    
    return danger;
}

float Utility_Shoot(const Vector3& myPos, const Vector3& enemyPos,
                    const Vector3& myAimDir, float ammo) {
    if (ammo <= 0) return 0.0f;
    
    Vector3 toEnemy = (enemyPos - myPos).Normalized();
    float aimScore = toEnemy.DotProduct(myAimDir); // 1.0 = perfect aim
    
    // LOS check with raycast
    bool clearLOS = RaycastClear(myPos, enemyPos);
    
    return aimScore * (clearLOS ? 1.0f : 0.0f);
}
```

**Visual feedback:** Rifleman raises weapon when `Utility_Shoot` is high, runs backward animation when `Utility_Retreat` wins.

### Axe Warrior — **The Approach Problem**

```cpp
// State: CHASE
void WarriorState_Chase::Update(float dt) {
    Vector3 toTarget = (riflemanPos_ - myPos_).Normalized();
    
    // If shot recently, enter evasive sub-state
    if (TimeSinceLastShot() < 0.3f && health_ > 0.5f) {
        // Zigzag perpendicular to aim direction
        Vector3 evadeDir = toTarget.CrossProduct(Vector3::UP);
        if (rand() % 2) evadeDir = -evadeDir;
        Move(evadeDir * sprintSpeed_);
    } else {
        // Direct approach, but circle-strafe at medium range
        float dist = (riflemanPos_ - myPos_).Length();
        if (dist > 8.0f) {
            Move(toTarget * sprintSpeed_); // Full sprint
        } else {
            // Circle-strafe to avoid being an easy target
            Vector3 circle = toTarget.CrossProduct(Vector3::UP);
            Move((toTarget * 0.6f + circle * 0.4f) * runSpeed_);
        }
    }
    
    if (dist < 2.5f) ChangeState(ATTACK_WINDUP);
}
```

**Visual feedback:** Warrior leans forward during sprint, weapon raised overhead during windup, heavy step sounds on approach.

## rbfx Implementation Tips

| Feature | rbfx Component |
|---------|---------------|
| Pathfinding | `NavigationMesh` + `CrowdManager` |
| Raycast LOS checks | `PhysicsWorld::RaycastSingle()` |
| Animation states | `AnimationController::PlayExclusive()` |
| Hit detection | `RigidBody` collision / trigger volumes |
| Aim IK | Your existing spine-aiming code, applied to rifleman's upper body |
| Evasive movement | Modify `Node` position directly, or use `CharacterController` |
